# Código de conduta

Este projeto é um estudo acadêmico sobre documentação, observabilidade e Sistemas Operacionais. A participação deve ser respeitosa, objetiva, acolhedora e compatível com um ambiente de aprendizagem.

Todas as pessoas devem ser tratadas com respeito, independentemente de experiência, função, identidade ou nível de participação. Críticas devem se concentrar no código, na documentação ou na proposta técnica, nunca em ataques pessoais.

Discussões devem permanecer relacionadas ao System Monitor, às Aulas 7 e 8 ou a temas necessários para compreender o projeto. Sugestões e correções devem ser recebidas de forma construtiva. Dados pessoais, credenciais e informações privadas devem ser protegidos.

Contribuições devem buscar clareza, reprodutibilidade e segurança. Quando houver divergência técnica, apresente evidências, explique os trade-offs e mantenha a conversa profissional.

## Comportamentos inaceitáveis

Não são aceitos assédio, discriminação, ameaças, insultos, humilhação, exposição de informações privadas, perseguição, spam ou qualquer tentativa de comprometer o serviço, o repositório ou o ambiente de outras pessoas.

Também não é aceitável publicar credenciais, explorar sistemas sem autorização, manipular evidências de validação ou apresentar uma funcionalidade inexistente como concluída.

## Comunicação de problemas

Relate situações de forma objetiva, com contexto suficiente para análise. Quando houver informação sensível, use um canal privado do GitHub e não publique dados pessoais ou detalhes exploráveis em espaços públicos.

Pessoas responsáveis pela moderação devem priorizar segurança, privacidade, imparcialidade e correção proporcional. O objetivo é manter o projeto adequado para estudo, colaboração e evolução técnica.

## Aplicação

A participação no projeto implica concordância com estas regras. Comportamentos inadequados podem resultar em solicitação de correção, remoção de conteúdo, encerramento de discussão ou restrição de participação, conforme a gravidade e o contexto.
